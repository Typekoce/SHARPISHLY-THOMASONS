### **Core Technical Profile of the Project**

* **Architecture:** Zero-dependency, lightweight MVC framework adhering strictly to DRY principles and schema-driven integration design.
* **Backend & Processing:** Native PHP and Python models, controllers, and workers managed via Supervisor, avoiding heavy framework bloat or raw SQL usage.
* **Infrastructure & Security:** Hardened Linux deployment environments, strict secret orchestration (HashiCorp Vault / Zero-Knowledge security-as-code), and automated local/remote Git hooks.
* **APIs & Integrations:** Multi-provider cloud and financial API orchestration (including AWS, Azure, Google Cloud, Stripe, and Xero) running through unified abstract base controllers.
* **Frontend & IO Bridge:** Node.js and React-based interface layers communicating via message-broker architectures.
