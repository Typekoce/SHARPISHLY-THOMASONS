✅ LESSONS LEARNED

    The Backbone Rule: Never add middleware (Redis, Vector DBs) until the raw HTTP handshake between services is 100% verified.

    Linearity > Parallelism: Python workers are easier to debug as simple while loops than as multi-threaded FastAPI applications during the early dev phase.

    The DMZ Principle: Use the Database as the only "Source of Truth." Python should never touch the DB directly if PHP is the Orchestrator; talk through the Controller instead.
